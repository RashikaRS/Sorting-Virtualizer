# Sorting Algorithm Visualizer

An interactive visualizer that shows how classic sorting algorithms solve the
same problem — comparing and swapping elements step by step, in real time.

## Features
- 5 algorithms: Bubble Sort, Selection Sort, Insertion Sort, Quick Sort, Merge Sort
- Adjustable array size and animation speed
- Live comparison and swap counters
- Color-coded bars: comparing (yellow), swapping (red), sorted (green)
- Fully responsive layout

## Tech Stack
- HTML5, CSS3
- Vanilla JavaScript (async/await for step-by-step animation, no libraries)

## How It Works
Each algorithm is implemented from scratch in JavaScript. Comparisons and
swaps are animated using `async/await` with a configurable delay, so the
exact behavior of each algorithm — including their different time
complexities — is visible on screen.

## How to Run
Open `index.html` in any browser — no build steps or dependencies required.
